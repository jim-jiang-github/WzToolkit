# WzToolkit Python dependencies -- needed to pack bin\wztool.exe and to run from source.
#
# Do NOT install these into the system Python. Double-click build.cmd (or run
# scripts\build.bat): it first downloads a portable CPython into .pyruntime\, then
# installs these requirements into .pylibs\ with that interpreter via
# PYTHONPATH. A fresh clone builds on a machine with no Python at all, and the
# system interpreter is never touched or consulted.
#
# First build needs network access (interpreter ~15 MB + wheels ~200 MB).
# To start over from scratch, delete .pyruntime\ and .pylibs\ and rebuild.
#
# KEEP THIS FILE PURE ASCII. pip 24 has no BOM and no coding cookie to go on, so it
# decodes this file with the system ANSI code page (cp936 on Chinese Windows); UTF-8
# comments there raise UnicodeDecodeError and abort the install. scripts\deps.py also
# feeds pip an ASCII-sanitised copy as a safety net.
#
# Sync manually: python scripts\deps.py
#
# Upper bounds are on purpose: opencv 5 / numpy 3 change algorithm defaults and would
# shift the scoring of the screenshot -> map search.
pyinstaller>=6.0,<7
pillow>=10.0,<14
numpy>=1.24,<3
# screenshot search; wztool still runs without it, only "find map by image" is off
opencv-python-headless>=4.8,<5
# classic-server (mxdclassic) Unity bundle extraction for the classic minimap
# library; pulled in lazily, other features run without it
UnityPy>=1.20,<2
